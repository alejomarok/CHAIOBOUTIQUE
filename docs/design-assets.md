# Imágenes de campaña CHAIOBOUTIQUE

Las cuatro imágenes se generaron con la herramienta incorporada `image_gen` de Codex, sin CLI ni API externa configurada. Fueron revisadas visualmente y exportadas a WebP con Sharp (calidad 84 para las tres primeras y 82 para el detalle, sin ampliar ni recortar). Las imágenes son material editorial de campaña generado con IA; no representan productos reales del catálogo.

| Archivo                                               | Dimensiones | Uso sugerido                                                            |
| ----------------------------------------------------- | ----------- | ----------------------------------------------------------------------- |
| `public/images/campaign/chaio-campaign-hero.webp`     | 1536 × 1024 | Hero principal, modelo en la mitad derecha y pared libre a la izquierda |
| `public/images/campaign/chaio-campaign-linen.webp`    | 1024 × 1536 | Editorial de lino y estilo                                              |
| `public/images/campaign/chaio-campaign-movement.webp` | 1024 × 1536 | Editorial de texturas y movimiento                                      |
